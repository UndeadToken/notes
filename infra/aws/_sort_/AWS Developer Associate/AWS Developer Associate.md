AWS Regions  
  
- AWS has Regions all around the world  
- Names can be us-east-1, eu-west-3 …  
- A region is a cluster of data centres  
- Most AWS services are region-scoped  
  
How to choose an AWS region?  
  
- Compliance:  
    - With data governance and legal requirements: data never leaves a region without your explicit permission  
    - Proximity to customers: reduced latency  
    - Available services within a Region: new services and new features aren’t available in every Region  
    - Pricing: pricing varies region to region and is transparent in the service pricing page  
  
AWS Availability Zones  
  
- Each region has many availability zones (usually 3, min is 3, max is 6) e.g. - ap-souteast-2a - ap-souteast-2b - ap-southeast-2c  
- Each availability zone (AZ) is one or more discrete data centre with redundant power, networking, connectivity  
- They’re separate from each other, so that they’re isolated from disasters  
- They’re connected with high bandwidth, ultra-low latency networking  
  
AWS Points of Presence (Edge Locations)
